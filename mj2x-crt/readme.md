# mj2x-crt

`mj2x-crt` is the native-side C runtime copied into projects generated by
`mj2x-cli --generate-xmake`.

It is intentionally separate from `mj2x-runtime`: this layer is only for code
emitted by StackC/RegC and for generated native build templates. Higher-level
runtime features can be connected later without making generated projects depend
on the in-repo runtime layout.
