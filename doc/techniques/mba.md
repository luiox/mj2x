# MBA（Mixed Boolean-Arithmetic / 混合布尔算术）

> 把算术运算改写成等价的位运算恒等式，让反编译出来的表达式不再是可读的 `a + b`。

| 项 | 值 |
|---|---|
| 对标术语 | jvmtp `obfuscation.mba`；业界通称 MBA / M BA 混淆 |
| 作用层 | RegIR pass（`applyMbaTransforms`） |
| 开关 | `--regc-obfuscate`（基础形态）/ `--regc-mba-deep`（深展开） |
| 后端 | RegC ✅ / LLVM ✅（超子集则整方法回退）/ StackC ❌ / VMC4 ❌ |
| 默认 | 关 |
| 状态 | ✅ 已落地 |

## 对抗什么

反编译器和人工阅读都依赖"运算符即语义"：`a + b` 一眼是加法。MBA 把加法拆成
位运算组合后，表达式的形式与它的数学含义脱钩——要确认"这堆位运算其实是加法"
得先做等价性推导，符号执行或 SMT 求解能解，但代价从"读"上升到"算"。

## 机制

**基础形态**：整数 `Add` 改写为按位恒等式。JVM 整型是模 2^N 补码，`a + b` 可以
写成含 `and` / `xor` / `not` / 移位的等价形式，例如

```text
a + b  ≡  (a ^ b) + 2 * (a & b)            // 进位链写法
       ≡  ~(~a - b)                        // 补码恒等
```

**深展开（`--regc-mba-deep`）**：`Add` 展开为 De Morgan / 进位链，链中夹
`mj2x_regc_barrier` 防编译器折叠；变体按 `(seed, site)` 选，同一函数内不同调用
点可以长成不同形状。

`barrier` 是关键：没有它，clang -O2 的常量传播和代数化简会把整条链折回原样，
变换等于白做。这也是为什么深 MBA 在 LLVM 侧受限——barrier 超出 LLVM 子集时
整方法回退未变换。

## 产物形态

```c
// 变换前
r3 = r1 + r2;

// 变换后（示意，实际形状按 seed/site 选）
_mj2x_regc_barrier(_mj2x_regc_current_context(), "mba");
r3 = (r1 ^ r2) + ((r1 & r2) << 1);
```

## 代价

| 维度 | 影响 |
|---|---|
| 性能 | 每个改写点多条指令；深 MBA 另有 barrier 调用开销 |
| 产物体积 | 膨胀，深展开按链长线性增长 |
| 可调试性 | 生成的 C 不再对应源码算术结构 |

## 已知绕过面

- **符号执行 / SMT**：MBA 是恒等式，代数上可判定。对抗的是"读"，不是"算"。
- **编译器折叠**：若 barrier 被去掉（或被 LTO 跨 TU 看穿），整条链会被折回。
  `--native-opt-level` 的 LTO 档是这里的压力点。

## 与其他技术的关系

- 与**立即数隐藏**正交：MBA 改运算符形状，立即数隐藏改常量来源。
- 与 **CFF** 顺序无关，但都排同一条 pass 链上。
- VMC4 不走本 pass：VM 层已有自己的混淆面。
